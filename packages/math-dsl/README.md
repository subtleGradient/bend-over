# Math DSL for Bend

Initial scaffold for `bend-over-math-dsl`. Version `0.1.0.0`.

The entrypoint is [`math.bend`](math.bend); it currently exports `square` for
`U32` values. More math DSL features can be added in later versions.

From the repository root, run `bend packages/math-dsl/example.bend` to get `49`
and `bend packages/math-dsl/PROOF.bend` to check the package law.
